# Fonts

Inter 4.1 and Newsreader (roman and italic), subset to Latin and the symbols the pages use, as WOFF2. Both are under the
SIL Open Font License 1.1 (the two OFL files here). Inter and Newsreader roman are variable, taken unchanged from the old
tool's `app/pages/assets/fonts/`, whose FONTS.md records the sources and the subsetting. The italic is the old tool's
variable italic fixed at weight 400, the only weight the pages set it in, its optical sizes kept (fontTools
`varLib.instancer`, 2026-11-04, #49): 83 KB instead of 135 KB on every material page.
